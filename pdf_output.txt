OJ 系统⼤作业说明
本⼤作业要求使⽤  Python 与  FastAPI 构建⼀个⼩型但功能完整的  Online Judge （ OJ ）系统。项⽬采⽤分
阶段开发⽅式，主要考查  Python ⼯程开发、异步编程、 REST API 、前端交互、进程控制、权限管理、⽇
志记录、数据持久化、⾃动化测试和  Git 协作规范。
本⽂档是本次⼤作业的完整要求。除⽂档中明确标记为 “ 选做 ” 的内容外，其余内容均为必做要求。验收
与评分以本⽂档为准。
1. 实验⽬标
完成本项⽬后，系统应⽀持以下完整流程：
1. ⽤⼾通过前端⻚⾯完成注册、登录和登出；
2. 教师创建并维护编程题⽬；
3. 学⽣在前端⻚⾯查看题⽬并提交  Python 源代码；
4. 系统创建提交记录，并异步启动评测；
5. 系统在独⽴⼦进程中运⾏学⽣代码；
6. 系统使⽤多个测试点进⾏评测；
7. 系统能够识别  AC、WA、RE、TLE 和 SE；
8. 系统记录提交状态、最终结果、得分及测试点⽇志；
9. 学⽣通过前端⻚⾯查看⾃⼰的提交与经过裁剪的⽇志；
10. 教师通过前端⻚⾯完成题⽬管理或提交管理；
11. 教师可以查看全部提交和完整评测⽇志；
12. 管理员可以管理⽤⼾、备份和恢复系统数据；
13. 服务重启后，题⽬、⽤⼾、提交和⽇志仍然存在。
